## 🚀 ติดตั้ง (ประมาณ 5 นาที)

**1. อัปโหลดไฟล์** ทั้งหมดขึ้นเซิร์ฟเวอร์ แล้วให้สิทธิ์เขียนไฟล์ (write permission) แก่โฟลเดอร์

```
config/    storage/    public/uploads/
```

**2. ตั้ง Document Root** ของโดเมน — แนะนำให้ใช้ Sub-Domain เช่น `cert.โรงเรียน.ac.th`

| ตั้งค่าเป็น | ผลลัพธ์ |
|---|---|
| โฟลเดอร์ `public/` ✅ **แนะนำ** | URL สวย (`/login.php`) และปลอดภัยที่สุด |
| โฟลเดอร์หลักของโปรเจกต์ | ใช้ได้เช่นกัน — ระบบจะพาไปที่ `/public/` ให้อัตโนมัติ |

> **Plesk:** Websites & Domains → Hosting Settings → **Document root** → เติม `/public` ต่อท้าย (เช่น `httpdocs/public`)

**3. เปิดเว็บไซต์** — ระบบจะพาไปหน้า **ติดตั้งระบบ** เอง

**4. กรอกข้อมูล 3 ส่วน** แล้วกด **ติดตั้งระบบ**
- 🗄️ **ฐานข้อมูล** — กด *ตรวจสอบการเชื่อมต่อ* ก่อน (ถ้ายังไม่มีฐานข้อมูล ระบบสร้างให้)
- 🏫 **หน่วยงาน** — ชื่อ ชื่อย่อ กลุ่มงานหลัก และตราสัญลักษณ์ (.png / .jpg / .ico)
- 🔑 **ผู้ดูแลระบบ** — ตั้งรหัสผ่านของบัญชี `admin`

เสร็จแล้ว! 🎉 ระบบจะพาไปหน้าเข้าสู่ระบบ และหน้าติดตั้งจะถูกปิดทันทีเพื่อความปลอดภัย

## 📖 เริ่มใช้งาน

```
สร้างโครงการ  →  อัปโหลดแม่แบบ  →  เพิ่ม/นำเข้ารายชื่อ  →  ✅ เผยแพร่อัตโนมัติ
```

1. **เข้าสู่ระบบ** → เมนู *โครงการ/กิจกรรม* → กด **เพิ่ม**
2. กดปุ่ม 🔧 ของโครงการ → **อัปโหลดแม่แบบ** (ภาพ A4 แนวนอน .jpg/.png ไม่เกิน 2 MB)
3. **ปรับรูปแบบ** ฟอนต์ สี ขนาด และระยะขอบ แล้วกด 🖨️ เพื่อดูตัวอย่าง PDF
4. **เพิ่มรายชื่อ** ทีละคน หรือ **นำเข้า** จาก Excel (ดาวน์โหลดไฟล์ตัวอย่างได้ในหน้านำเข้า)
5. โครงการที่มีแม่แบบแล้วจะแสดงที่หน้าแรกทันที — ส่งลิงก์เว็บให้นักเรียนค้นหาและดาวน์โหลดได้เลย

> 🎨 ไม่มีแม่แบบ? ดาวน์โหลดไฟล์ Photoshop (.psd) ตัวอย่างได้ที่เมนู **เทมเพลต**

**ตั้งค่าเพิ่มเติม** (เฉพาะ `admin`) — เมนู *ตั้งค่าระบบ*: ข้อมูลหน่วยงานและตราสัญลักษณ์ · กลุ่มสาระ/งาน · ผู้ดูแลระบบ

## 🔄 อัปเดตเวอร์ชัน

อัปโหลดไฟล์เวอร์ชันใหม่ทับได้เลย — ค่าตั้งค่า (`config/config.php`), แม่แบบ และตราสัญลักษณ์ที่อัปโหลดไว้จะไม่ถูกเขียนทับ
ถ้าเวอร์ชันใหม่มีการเปลี่ยนแปลงฐานข้อมูล ระบบจะขอให้ `admin` เข้าสู่ระบบแล้วกด **อัปเดตฐานข้อมูล** — ข้อมูลเดิมอยู่ครบ

<details>
<summary><b>อัปเดตจากเวอร์ชัน 3.x</b> (คลิกเพื่อดูขั้นตอน)</summary>

เวอร์ชัน 4 จัดโครงสร้างโฟลเดอร์ใหม่ทั้งหมด แต่**ใช้ฐานข้อมูลเดิมได้ทันที โดยไม่แก้ไขข้อมูลเดิม**

1. สำรองแม่แบบที่อัปโหลดไว้: `upload/tempate/` และ `upload/preview/` (และตราสัญลักษณ์ `img/fav.ico`)
2. ลบไฟล์เวอร์ชันเดิมทั้งหมด แล้วอัปโหลดเวอร์ชันใหม่
3. นำไฟล์กลับ: `upload/tempate/*` → `storage/uploads/templates/` และ `upload/preview/*` → `storage/uploads/previews/`
4. เปิดเว็บ แล้วกรอก**ข้อมูลฐานข้อมูลเดิม** (ดูได้จากไฟล์ `connect.php` เดิม) → กด *ตรวจสอบการเชื่อมต่อ* — ระบบจะพบข้อมูลเดิมและข้ามการสร้างผู้ดูแลใหม่
5. เข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่านเดิม แล้วอัปโหลดตราสัญลักษณ์ใหม่ที่ *ตั้งค่าระบบ → ตั้งค่าทั่วไป*

✅ ลิงก์และ QR code บนเกียรติบัตรที่ออกไปแล้วยังใช้งานได้ตามเดิม

> ⚠️ เมื่อผู้ใช้ล็อกอินบนเวอร์ชัน 4 รหัสผ่านจะถูกแปลงเป็นรูปแบบที่ปลอดภัยขึ้น ซึ่งเวอร์ชัน 3 อ่านไม่ได้ — หากต้องการย้อนกลับไปใช้เวอร์ชัน 3 ควรสำรองฐานข้อมูลไว้ก่อน

</details>

## ❓ แก้ปัญหาที่พบบ่อย

<details>
<summary><b>เปิด <code>/login.php</code> หรือ <code>/install.php</code> แล้วขึ้น 404</b></summary>

เซิร์ฟเวอร์ใช้ Nginx (หรือ Plesk บางรูปแบบ) ซึ่งไม่อ่านไฟล์ `.htaccess` — ให้ตั้ง Document Root เป็นโฟลเดอร์ `public/` (ดูขั้นตอนติดตั้งข้อ 2) หรือเปิดผ่าน `/public/login.php` แทน
</details>

<details>
<summary><b>ลืมรหัสผ่าน admin</b></summary>

รันคำสั่งนี้ใน phpMyAdmin (เปลี่ยน `รหัสใหม่` เป็นรหัสที่ต้องการ) — ระบบจะแปลงเป็นรูปแบบที่ปลอดภัยให้เองเมื่อเข้าสู่ระบบครั้งถัดไป

```sql
UPDATE admin SET password = MD5('รหัสใหม่') WHERE username = 'admin';
```
</details>

<details>
<summary><b>ต้องการย้ายฐานข้อมูล / ติดตั้งใหม่</b></summary>

ลบไฟล์ `storage/installed.lock` และ `config/config.php` แล้วเปิดเว็บอีกครั้ง — ระบบจะกลับไปหน้าติดตั้ง
</details>

<details>
<summary><b>อัปโหลดไฟล์ไม่ได้ / ขึ้นว่าไฟล์ใหญ่เกิน</b></summary>

- แม่แบบเกียรติบัตรและตราสัญลักษณ์ไม่เกิน **2 MB**, ไฟล์รายชื่อไม่เกิน **5 MB**
- ตรวจสอบค่า `upload_max_filesize` และ `post_max_size` ใน PHP ของเซิร์ฟเวอร์ให้มากกว่าขนาดไฟล์
- ตรวจสอบสิทธิ์เขียนไฟล์ของโฟลเดอร์ `storage/` และ `public/uploads/`
</details>

<details>
<summary><b>เข้าสู่ระบบผิดหลายครั้งแล้วถูกล็อก</b></summary>

ระบบล็อกชั่วคราว 15 นาทีหลังกรอกรหัสผิด 5 ครั้ง (ปรับได้ใน `config/config.php` หัวข้อ `login`) — รอครบเวลา หรือลบไฟล์ในโฟลเดอร์ `storage/throttle/`
</details>

## 🔒 ความปลอดภัย

- 🛡️ ป้องกัน **SQL Injection** และ **XSS** ทุกจุด (prepared statement + escape ข้อมูลก่อนแสดงผล)
- 🔑 รหัสผ่านเข้ารหัสด้วย **bcrypt** และล็อกชั่วคราวเมื่อกรอกรหัสผิดเกินกำหนด
- 🎫 **CSRF Token** ในทุกการส่งข้อมูล รวมถึงการเข้าสู่ระบบ — และสร้าง session ใหม่ทุกครั้งที่ล็อกอิน
- 👮 ตรวจสอบสิทธิ์ทุก API — ผู้ดูแลจัดการได้เฉพาะโครงการในกลุ่มของตน
- 📁 ตรวจสอบไฟล์อัปโหลดจากเนื้อหาจริง ไม่ใช่แค่นามสกุล
- 🚪 หน้าติดตั้งปิดตัวเองหลังติดตั้งเสร็จ และโฟลเดอร์ระบบอยู่นอกเว็บทั้งหมด

```
│   ├── assets/             css, js (app.js + pages/), img, vendor (Atlantis, DataTables)
│   ├── uploads/            ตราสัญลักษณ์ที่อัปโหลด
│   └── downloads/          ไฟล์ตัวอย่าง Excel และ .psd

│   ├── layouts/            head, navbar, sidebar, footer
│   ├── components/modals/  ฟอร์ม popup
│   └── pages/              เนื้อหาแต่ละหน้า + certificate.php (HTML ของ PDF)
├── backend/                ⚙️ การทำงานทั้งหมด
│   ├── Core/               Database, Auth, Csrf, Session, Request, Response, Api, DataTable, View
│   ├── Models/             Project, Participant, Admin, Department, School
│   ├── Services/           CertificateNumber, CertificatePdf, TemplateStorage, ParticipantImporter,

│   ├── Controllers/        Logic ของ API แต่ละตัว
│   └── resources/fonts/    ฟอนต์ไทยสำหรับ PDF
├── config/                 config.example.php (ค่าเริ่มต้น) + config.php (สร้างจากหน้าติดตั้ง)
├── database/migrations/    ไฟล์ .sql รันตามลำดับชื่อไฟล์
├── storage/                ไฟล์ที่ระบบเขียน (แม่แบบ, throttle, installed.lock)
└── vendor/                 Composer: mPDF, PhpSpreadsheet
```

### ลำดับการทำงาน

```
หน้าเว็บ :  เบราว์เซอร์ → public/*.php → backend/ (สิทธิ์, ข้อมูล) → frontend/pages/*
API      :  js/app.js   → public/api/*.php → backend/Controllers/* → JSON
```

### งานที่พบบ่อย

- **เพิ่มตาราง/คอลัมน์** — สร้างไฟล์ `database/migrations/002_ชื่อ.sql` ระบบจะพา admin ไปกดอัปเดตเอง
- **อัปเดตไลบรารี** — `composer update` แล้ว commit โฟลเดอร์ `vendor/` (เซิร์ฟเวอร์ส่วนใหญ่ไม่มี Composer)
- **โหมด debug** — ตั้ง `'debug' => true` ใน `config/config.php` หัวข้อ `app` (ห้ามเปิดบนเซิร์ฟเวอร์จริง)
